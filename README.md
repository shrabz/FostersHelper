# Fosters Service

**Fosters Service** — утилита для обслуживания Windows, диагностики ПК, игровых оптимизаций, стресс-тестов и поддержки пользователей.

Программа создана для быстрого анализа состояния компьютера, настройки системы под игры, проверки железа и удобной связи с поддержкой.

---

## Возможности

### Игровая оптимизация

- Быстрый пресет **CS2 Esports Mode**
- Профили оптимизации:
  - CS2 / FPS
  - Минимальный input lag
  - Стриминг
  - Слабый ПК
  - Ноутбук / энергосбережение
  - Вернуть Windows stock
- Отключение лишних фоновых служб
- Очистка Standby Memory
- Настройка GameDVR / Game Bar
- MMCSS игровой профиль
- CPU Core Parking OFF
- Power Throttling OFF
- PCIe Link State OFF
- USB Selective Suspend OFF
- HAGS / MSI Mode
- Приоритет CS2 = High

## Fosters OPTIMIZER PRO

Платный модуль для расширенной оптимизации и обслуживания ПК.

### Что входит в PRO

- **Fosters OPTIMIZER**
  - автозапуск;
  - поиск игры;
  - очистка фоновых процессов;
  - возврат служб после выхода из игры.

- **Error Doctor**
  - поиск критических ошибок Windows;
  - объяснение влияния ошибки;
  - запуск исправления через DISM, SFC, WMI, CHKDSK.

- **Startup Control**
  - просмотр приложений в автозагрузке;
  - просмотр служб;
  - описание каждого пункта;
  - отключение лишнего из автозапуска.

- **Smart Cleaner**
  - поиск старых временных файлов;
  - поиск старых игровых и пользовательских файлов;
  - выбор перед удалением;
  - защита системных директорий, драйверов и важных файлов.

- **Input Lag PRO**
  - комплексный профиль снижения задержки ввода;
  - отключение лишних оверлеев;
  - настройки питания, USB, PCIe и Game Mode.

- **Профили оптимизации**
  - готовые сценарии под разные задачи.

### Подписка

В программе отображается:

- статус подписки;
- тариф;
- остаток дней;
- HWID;
- статус заморозки;
- доступные PRO-модули.

Подписку можно заморозить один раз в 30 дней.

## Проверка Windows

Встроенный модуль **Windows Health** показывает состояние системы в формате `OK / WARN / FAIL`.

Проверяется:

- права администратора;
- версия и build Windows;
- WMI / CIM;
- Microsoft Defender;
- Windows Update;
- точки восстановления;
- DISM CheckHealth;
- Kernel-Power 41;
- BSOD / BugCheck;
- WHEA hardware errors;
- ошибки disk / NTFS;
- сбои служб Windows;
- Storage Health.

Для каждой проблемы программа показывает:

- что найдено;
- на что влияет;
- что сделать дальше.

## Диагностика и стресс-тесты

В программе есть инструменты для проверки стабильности ПК:

- Fosters OCCT Stability
- GPU Stress
- VRAM Stress
- RAM / Cache test
- CPU test
- FPS Benchmark
- Fosters GPU-Z
- Fosters CPU-Z
- Fosters Disk Info
- Fosters Disk Mark

После тестов сохраняется история:

- дата;
- железо;
- температуры;
- ошибки;
- длительность;
- итог OK / WARN / FAIL.

Также есть автоотчет после завершения теста и возможность отправить отчет в поддержку.

## Вердикт ПК

Программа формирует понятный итог состояния компьютера:

- игровая готовность;
- температуры;
- RAM / XMP;
- GPU;
- диски;
- автозагрузка;
- общий вывод.

Поддержка
Встроен онлайн-чат с поддержкой.
Возможности:
отправка сообщений;
отправка скриншотов;
отправка видео;
передача номера заказа;
передача конфигурации ПК;
быстрый ответ от поддержки.
Также добавлена обратная связь через Telegram-бота.
Community Tweaks
Пользователи могут добавлять свои твики.
Поддерживается:
название;
описание;
категория;
скрипт;
прикрепленные файлы;
рейтинг;
отзывы.
Администратор может удалять подозрительные твики и блокировать пользователей.
